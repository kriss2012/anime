## 📖 About The Project

**Mend** is a premium, visually stunning single-page web application designed to guide users through a comforting, scroll-driven mental health journey. Leveraging modern design principles, interactive animations, and responsive layouts, the app serves as a safe digital space to reflect, pause, and breathe.

From the dark, stormy rain effects representing inner struggles, to the glowing particles and plant growth symbolizing recovery and future readiness, the application is crafted to be emotionally resonant, responsive, and fully optimized for mobile devices.

---

## ✨ Interactive Storytelling Chapters

Each section is beautifully choreographed with distinct colors, typography, and interactive components:

### ⛈️ Chapter I: The Storm
*A moody, rain-filled landing representing the weight of dark thoughts.*
- **Interactive Environment:** Simulated rain particles falling down the screen and randomly triggered lightning flashes.
- **Milestone Stats:** Encouraging real-time indicators emphasizing strength, small steps, and growth.

<img src="https://raw.githubusercontent.com/kriss2012/anime/main/vite-project/public/images/hero_preview.png" alt="Chapter 1 Preview" width="100%" style="border-radius: 8px; margin-bottom: 20px" />

### 🌀 Chapter II: The Struggle
*Validating the heavy emotions and internal spirals.*
- **Reflective Writing:** Validating feelings of isolation, anxiety, and the quiet loop of thoughts.
- **Story Deck:** Interactive wellness cards detailing emotional blocks ("The Spiral", "The Weight of Silence") to help process difficult phases.

<img src="https://raw.githubusercontent.com/kriss2012/anime/main/vite-project/public/images/struggle_preview.png" alt="Chapter 2 Preview" width="100%" style="border-radius: 8px; margin-bottom: 20px" />

### ☀️ Chapter III: The Healing
*Transitioning into light, sunrise, and structured mindfulness.*
- **Sunbeam Overlay:** Calming warm gradients and flying birds representing hope and clarity.
- **Deep Breathing Guide:** Integrated visual cues for structured inhale-hold-exhale exercises.

<img src="https://raw.githubusercontent.com/kriss2012/anime/main/vite-project/public/images/healing_preview.png" alt="Chapter 3 Preview" width="100%" style="border-radius: 8px; margin-bottom: 20px" />

### 🌿 Chapter IV: The Growth
*Visualizing progress through the quiet bloom of nature.*
- **Organic Growth Animation:** Custom CSS keyframes animating root systems, stems, and flower petals blooming when scrolled into view.
- **Calming Metaphor:** Illustrating that growth doesn't announce itself—it simply blooms when conditions are right.

<img src="https://raw.githubusercontent.com/kriss2012/anime/main/vite-project/public/images/growth_preview.png" alt="Chapter 4 Preview" width="100%" style="border-radius: 8px; margin-bottom: 20px" />

### 🚀 Final Chapter: The Future
*Acceptance, victory, and daily tools for maintaining peace.*
- **Daily Toolset Grid:** Handpicked practices covering Mindfulness, Movement, Sleep Hygiene, Connection, Creative Expression, and Nature Therapy.
- **Particle System:** Floating ember particles drifting upward against a bright sunrise backdrop.

## 📱 Mobile & Responsive Architecture

Mend has been optimized to ensure full responsiveness and compatibility across narrow Android screens:
- **Sticky Glassmorphic Header:** Uses root-level fixed positioning (`position: fixed`) and `backdrop-filter: blur` to float cleanly over all sections without index clipping.
- **Flexible Grid Flow:** Layout wraps dynamically from rows on desktop to structured columns on mobile viewports.
- **Centered Coordinate Scaling:** Absolute plant growth boundaries are scaled down dynamically under `768px` to guarantee zero screen overflow.

## 🚀 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kriss2012/anime.git
   cd anime/vite-project
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local server:**
   ```bash
   npm run dev
   ```
4. **Open in browser:** Navigate to `http://localhost:5174/`.
